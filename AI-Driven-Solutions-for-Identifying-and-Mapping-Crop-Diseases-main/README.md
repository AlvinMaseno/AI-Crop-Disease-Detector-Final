# Crop Disease Detector - Flutter Frontend

A modern, farmer-friendly Flutter mobile application for AI-driven crop disease identification and mapping.

## 🌱 Features

- **Smart Disease Detection**: Upload crop images for AI-powered disease identification
- **Disease History**: Track and manage your crop disease reports
- **Community Resources**: Access agricultural tips and useful links
- **Multi-language Support**: Available in English and Kiswahili
- **Modern UI**: Clean, Material 3 design with agricultural theme
- **Weather Integration**: Daily weather information for better crop management

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Dart SDK
- Android Studio / VS Code
- Android/iOS device or emulator

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd crop-disease-detector
```

2. Install dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```
